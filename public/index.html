Codebase Explainer

A multi-agent RAG assistant that answers architecture questions about a codebase. It searches code and documentation together, checks whether the evidence is enough, searches again if it is not, and answers with citations. If the repository does not cover the question, it should say so.

This is a project page, not the running app. The system needs a Qdrant index of the target repository (Backstage) plus OpenAI and Voyage AI API keys, and uses a human review interrupt, so it is not hosted here. Everything below comes from the repository: the pipeline design, the evaluation question set and the reported metrics. The reference answers shown are the ground truth written for evaluation, not live model output.

The problem

Questions such as "how does authentication work in this service?" are rarely answered by a single file. The answer is spread across a README, a config module, middleware and a utility several folders away. A plain RAG chatbot retrieves once and answers from an incomplete picture, and the answer still sounds confident.

This project treats retrieval as part of the reasoning loop. The system decides mid-answer whether it needs another search hop, and it is evaluated on whether it correctly refuses to answer when the evidence is missing.

How it works

  • Decompose splits the question into search queries and tracks a checklist of what must be found.
  • Search is hybrid retrieval over Qdrant. Dense vectors use voyage-code-3, sparse vectors use BM25 (fastembed), and results are reranked with Voyage rerank-2. Code and documentation live in separate collections.
  • Coverage check decides whether the gathered chunks are sufficient. It stops after 3 hops, or earlier if a hop adds no new chunks, and the response step then abstains.
  • Response and citation check writes the answer, then verifies that each claim is supported by a cited chunk (up to 2 rewrites).
  • Human verify is an interrupt step where a reviewer approves or rejects the answer. Rejection with feedback sends the question back to decompose, up to 2 times.

The agent graph is built with LangGraph. Tracing is optional through Arize Phoenix. The target repository indexed for the evaluation is Backstage.

The evaluation question set

21 questions are answerable and list the full set of source files needed to answer them. 10 are deliberately unanswerable, and the correct behavior is to abstain. Open a question to see its reference answer and gold source files.

Tech stack

Python 3.11+, LangGraph, LangChain, OpenAI (gpt-4o-mini), Qdrant, Voyage AI, fastembed, LlamaIndex (code splitting), FastAPI, RAGAS, Arize Phoenix, Docker.

Status

Work in progress. The retrieval, agent graph, API and evaluation harness are written. The setup in the README has not been verified end to end. Planned: fix abstention, verify the Docker setup, add a unit test suite that needs no API keys, and record a demo.
