# CLAUDE.md

## Priority Rules

### Before making any code changes
Always follow this order:
1. Explain the issue
2. Propose the potential solution
3. Ask the user if they want the change applied

Never edit files directly without going through these three steps first, unless the user explicitly asks to "fix", "correct", "apply", or "do it".

### Response style
- Precise, on-point, straightforward.
- No padding, no re-summarising, no filler intros/outros.
- Bullets and tables over paragraphs when they carry the same information.
- Answer the question asked. Stop.
